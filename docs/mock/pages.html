Bookings page

Bookings in date order, with type filters on top. Hotel stays show as a span across their nights. The selected hotel's details open on the right: confirmation, check-in and check-out, the nights it sets as the base, cancellation deadline, attached file, and whether it counts in the budget. Bookings with a time are linked to a fixed block in the timetable.

Budget page

One trip budget, in the home currency, split into categories with their own limits. Each cost stays in the currency it is paid in, and each currency has its own column (here ¥ JPY and $ USD for the flights). Totals are in the home currency (a TWD / USD menu, open in the mock) using rates the user types in. Flights are included. The day chart shows planned spending per day in TWD. The "Actual" column is greyed out: it is a placeholder for spending logged during the trip later.

Static mock with invented bookings, prices and confirmation numbers. The exchange rates (1 JPY = 0.21 TWD, 1 USD = 32 TWD) are sample values a user would type in, not real rates. Colours, fonts and icons are placeholders, not a chosen theme.
